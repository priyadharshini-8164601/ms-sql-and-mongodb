## Contents

The repository is organized into daily assignments, with each day containing three sets of practical tasks based on different business scenarios.

Each set includes SQL Server scripts, MongoDB scripts, and a README file explaining the tasks performed.

The assignments cover:

- Database creation and management.
- SQL queries and data manipulation.
- SQL built-in and aggregate functions.
- GROUP BY, HAVING, and ORDER BY.
- Different types of JOINs.
- Subqueries and correlated subqueries.
- Common Table Expressions (CTEs).
- Window functions such as ROW_NUMBER, RANK, DENSE_RANK, LEAD and LAG.
- SQL transactions, COMMIT, ROLLBACK and SAVEPOINT.
- Transaction isolation levels and ACID properties.
- MongoDB CRUD operations and aggregation pipelines.
- MongoDB $lookup, $inc and multi-document transactions.

## Tools Used

- Microsoft SQL Server 2025
- SQL Server Management Studio (SSMS)
- MongoDB 8.0
- MongoDB Compass
- MongoDB Shell (mongosh)

## Learning Outcomes

Through these assignments, I practiced writing SQL queries, managing relational databases, analysing data using joins and subqueries, implementing transactions, generating reports using window functions, and working with MongoDB collections and aggregation pipelines.

## Execution

1. Open the required `.sql` file in SQL Server Management Studio and execute the queries.
2. Open the corresponding `.js` file in MongoDB Shell or MongoDB Compass and execute the MongoDB commands.
3. Refer to the individual README files for details about each assignment.
